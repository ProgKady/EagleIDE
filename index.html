Module 04 / Arduino Simulator

Physics-Driven
Arduino Simulator

Powered by the E38 Motion Engine, the simulator models microcontrollers, ICs, sensors, motors, and passive components using Modified Nodal Analysis (MNA). It simulates back-EMF, thermal filament curves, motor spin-ups, and servo pulse slew in real time.

Features bidirectional code-to-circuit generation (place parts to emit C++ or paste code to build circuits), a 4-channel oscilloscope, edge-triggered logic analyzer with UART/I2C decoders, and magnetic snapping.
